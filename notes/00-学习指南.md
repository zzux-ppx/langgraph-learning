# 00 - 学习指南

## 这个仓库怎么用

1. **先读笔记，再跑代码**：每篇笔记 `notes/XX-xxx.md` 都对应一个可运行脚本 `code/XX_xxx.py`，边读边跑效果最好。
2. **改代码做实验**：每个脚本都在关键位置留了"动手实验"注释，改一改、跑一跑，比读十遍都有用。
3. **笔记中的代码片段刻意精简**（省略 import 等），完整可运行版本以 `code/` 下脚本为准。
4. **学完 1-11 篇后去读 12-13 原理篇**，再对照 `code/deep_dive/mini_langgraph.py`（手写迷你版）巩固。
5. 最后跑通 `project/` 综合项目，检验是否真的掌握。

## 前置知识

- Python 3.10+（会用到 `TypedDict`、`Annotated`、类型注解）
- 了解 LLM 基本概念（messages、tool calling）即可，**不要求先学 LangChain**
  ——LangGraph 1.x 是独立框架，不依赖 LangChain 的链/Agent 抽象。

## 常见疑问 FAQ

**Q: LangGraph 和 LangChain 什么关系？**
同一公司（LangChain Inc.）出品，但 LangGraph 是独立的底层编排框架，
只依赖 `langchain-core`（提供消息等基础类型）。可以完全不用 LangChain 的链。

**Q: LangGraph 和 CrewAI/AutoGen 有什么区别？**
那两者是"多Agent框架"，提供现成的角色协作范式；LangGraph 是更底层的
**图编排运行时**——把应用建模为状态图，Agent 只是你放在节点里的一种东西。
灵活度更高，代价是很多模式要自己搭（官方也提供了 `create_agent` 等高层封装）。

**Q: 学 LangGraph 必须用 LangSmith 吗？**
不必须。本仓库所有代码都不用 LangSmith。生产环境建议配合使用（可视化调试很香）。

**Q: 为什么我的图报 `GraphRecursionError`？**
默认 `recursion_limit=25`，即最多 25 个"超步"。通常是条件边的循环出口写错了。
见笔记 03。
